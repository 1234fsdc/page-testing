# dev-scanner

全自动浏览器项目扫描器。对前端项目做 8 个维度的全方位检查，输出结构化审计报告。

## 功能

- **项目检测**：自动识别 React / Vue / Next / Nuxt / 纯静态项目
- **路由发现**：从 router 配置 / 文件系统 / 首页爬取自动发现页面
- **逐页扫描**：
  - A. UI/视觉设计审查（布局、响应式、组件状态、对比度、图片）
  - B. 功能交互测试（链接、表单、核心流程、交互组件）
  - C. 控制台 & 网络监控（JS 错误、API 失败、弃用警告）
  - D. 可访问性基础（键盘导航、焦点、ARIA、触控目标）
  - E. 性能基础（加载时间、大图、渲染阻塞）
  - F. 内容合理性（占位文本、死链、Meta 标签、404 页面）
- **结构化报告**：每个问题详细描述现状、影响、代码位置

## 依赖

- [browser-use](https://github.com/browser-use/browser-harness) — 浏览器 CDP 控制
- Chrome 浏览器（需开启远程调试）

## 安装

将 `SKILL.md` 放入 `~/.agents/skills/dev-scanner/` 即可被 ZCode 自动发现。

## 使用

说出以下关键词自动触发：
- `审计项目` / `扫描项目` / `全面检查` / `跑一遍检查`
- `检查UI` / `检查设计` / `检查页面`
- `review project` / `audit project`

## 报告示例

报告保存在 `项目根目录/audit-reports/audit-report-YYYY-MM-DD-HHmm.md`

```
# 📊 campus-second-hand-market - 浏览器审计报告

## 📈 概览统计
| 发现页面 | 总问题数 | 🔴 严重 | 🟠 主要 | 🟡 次要 |
|---------|---------|---------|---------|---------|
| 7       | 14      | 3       | 4       | 5       |

## 📄 逐页详情
### 🔐 /login (登录页)
#### 🟠 表单输入框缺少 name 属性
**现状**：登录表单的两个 input 元素都没有 name 属性...
**影响**：屏幕阅读器无法识别字段，密码管理器无法工作...
**代码位置**：`src/views/LoginView.vue:46`
```

## 注意事项

- 需要开启 Chrome 远程调试：`chrome://inspect/#remote-debugging`
- 20+ 页面扫描约需 5-15 分钟
- 不修改项目代码，只读不写
